## Fixed

- `client` [NHL-111] Overlay icons can no longer "fall off" the left edge of the chart.  By default we render team logos for all the teams at a given point on the Y-axis, for a given date, in a row from right-to-left. If the mouse is close the left edge of the chart, however, it's very possible for such a row of logs to "not all fit" inside of the chart real estate. If all the rows won't fit, we now "flip them over" by drawing them from left-to-right instead of right-to-left.
